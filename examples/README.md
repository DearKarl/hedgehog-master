# Hedgehog Master Example Projects

> Curated example projects generated by Hedgehog Master.

> Example artifacts are frozen snapshots of the workflow and capability boundary that generated them. Their `design_spec.md` and `spec_lock.md` files may retain rules that were later relaxed; they are historical evidence, not current SVG authoring authority. Use [`shared-standards.md`](../skills/hedgehog-master/references/shared-standards.md) for current required, forbidden, and conditional rules.

The local catalog is powered by [`examples.json`](./examples.json), which is the source of truth for project metadata, tags, slide listings, and publication status. The public gallery includes only reviewed English-language examples. Multilingual frozen snapshots may remain tracked as regression references but use `published: false` and are not shown in the product interface. Start the repository web server and open `http://127.0.0.1:4173/` to browse the published set.

## Project Structure

Each example follows this layout:

```
<project_name>/
├── design_spec.md       # Design specification (human-readable)
├── spec_lock.md         # Machine-readable execution contract
├── images/              # Image assets
├── notes/               # Speaker notes per page
├── svg_output/          # Original SVGs (with placeholders)
└── svg_final/           # Self-contained preview SVGs (icons + images embedded)
```

> Examples deliberately omit `sources/` (original PDFs / DOCX) and `exports/` (PPTX output) to keep repo size small. Real projects under `projects/` will have both.

## Preview locally

```bash
python -m http.server --directory examples/<project_name>/svg_final 8000
# visit http://localhost:8000
```

Or open any `svg_final/*.svg` directly in a browser / VS Code.

## Contributing

New or deliberately refreshed examples need (1) the standard structure above and (2) an entry in [`examples.json`](./examples.json) (`projects[]` array + bumped `stats`). Set `published: true` only after the metadata and visible slides have passed the English-language and visual review. Their SVGs should pass `python3 skills/hedgehog-master/scripts/svg_quality_checker.py`; existing frozen snapshots are not retroactively rewritten solely to match a newer authoring policy.
