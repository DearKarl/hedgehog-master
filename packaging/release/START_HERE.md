# Hedgehog Master v__VERSION__

[English](#english) | [中文](#中文)

## English

1. Keep `Hedgehog Master.app`, `hedgehog_master`, and `setup.command` in this folder.
2. Double-click `setup.command` once to install the local Python environment.
3. Double-click `Hedgehog Master.app` whenever you want to open the workbench.
4. Runtime files and projects are stored under `~/Library/Application Support/Hedgehog Master`, so upgrades do not overwrite your work.

Requirements: macOS 12 or newer, Python 3.11 or newer, and Node.js 20 or newer. The app runs only on `127.0.0.1`; it does not expose the workbench to the public network.

This beta build is ad-hoc signed for local evaluation and is not notarized. macOS may ask you to confirm the first launch.

## 中文

1. 请将 `Hedgehog Master.app`、`hedgehog_master` 和 `setup.command` 保持在同一个文件夹中。
2. 首次使用时双击 `setup.command`，安装本地 Python 环境。
3. 以后双击 `Hedgehog Master.app` 即可打开工作台。
4. 运行文件和项目保存在 `~/Library/Application Support/Hedgehog Master`，升级不会覆盖工作内容。

环境要求：macOS 12 或更高版本、Python 3.11 或更高版本，以及 Node.js 20 或更高版本。应用只监听 `127.0.0.1`，不会把工作台暴露到公网。

此测试版仅使用本地临时签名，尚未进行 Apple 公证。macOS 首次启动时可能要求确认。
