How to use Hedgehog Master

1. Prepare the research inputs

Start with a clear brief. Add an optional PPTX template, papers or research documents, and code or pseudocode. The template controls the visual background; sources and code ground the scientific content.

2. Create and plan

Create the project with automatic planning enabled. The local planner registers sources, extracts cited claims, builds a storyboard, selects a Diagram IR type, and records formula and image tasks.

3. Review the evidence

Open the project inspector and check source, claim, diagram, formula, and image counts. Plan can be rerun after changing the brief or replacing inputs.

4. Validate, build, and export

  1. Plan updates the semantic research model.
  2. Validate checks schemas, citations, files, and asset references.
  3. Build SVG compiles deterministic diagrams and slide visuals.
  4. Export PPTX creates the editable presentation in the project exports folder.

External image generation

Choose automatic image generation only when an image backend and API key are configured. Manual mode keeps an auditable prompt manifest without calling a paid service.
