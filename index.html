How to use Hedgehog Master

1. Ask for a contract, not a miracle

Open the Template tab, choose the page count and page ingredients, then generate a JSON contract. It is less glamorous than shouting “make my slides”, but dramatically easier to audit.

2. Let your own model do the writing

Send that JSON to the language model you already use. Add your resume, paper, notes, or instructions in the same conversation. Ask it to replace every placeholder and return JSON only.

3. Bring the ingredients home

Paste the filled JSON into New project. Upload any requested figures and assign each file to its slide. Hedgehog Master checks IDs, lengths, sources, LaTeX, and missing images before layout.

4. Build the deck without layout roulette

  1. Plan preserves the approved external content contract.
  2. Validate checks schemas, citations, files, and asset references.
  3. Build SVG compiles deterministic slide visuals.
  4. Export PPTX creates the editable presentation in the project exports folder.

Choose what each page must contain. The generated JSON is a prompt contract for your own model, not an API call from this app.
